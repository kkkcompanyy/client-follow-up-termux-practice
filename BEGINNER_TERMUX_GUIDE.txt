4) UBUNTU WITH PROOT-DISTRO

    proot-distro install ubuntu:24.04
    proot-distro login ubuntu

Inside Ubuntu:

    apt update
    apt install -y curl wget ca-certificates gnupg

5) NGROK INSIDE UBUNTU

Official APT install pattern:

    curl -sSL https://ngrok-agent.s3.amazonaws.com/ngrok.asc \
      | tee /etc/apt/trusted.gpg.d/ngrok.asc >/dev/null

    echo "deb https://ngrok-agent.s3.amazonaws.com bookworm main" \
      | tee /etc/apt/sources.list.d/ngrok.list

    apt update
    apt install -y ngrok

Then add YOUR OWN account token:

    ngrok config add-authtoken "<YOUR_AUTHTOKEN>"

With Flask running in another Termux session:

    ngrok http 5000

6) CLOUDFLARED INSIDE UBUNTU

    mkdir -p --mode=0755 /usr/share/keyrings

    curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg \
      | tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null

    echo "deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main" \
      | tee /etc/apt/sources.list.d/cloudflared.list

    apt-get update
    apt-get install -y cloudflared

Quick tunnel:

    cloudflared tunnel --url http://127.0.0.1:5000
